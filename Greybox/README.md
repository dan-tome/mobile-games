# Greybox (throwaway)

Phase 0 fun check for the colour-mixing tray puzzle. Hand-made levels, no engine. Delete once the Phase 0 gate is decided.

- Play: open the published link on your phone, or serve this folder (`python3 -m http.server`) and open `index.html`.
- Check levels after editing `levels.js`: `node Greybox/solve.mjs` (solvable, best-play slack, sampled trap ratio).
- Playtest stats live on the device. Stats > Copy results gives JSON to paste back to Claude.
